# Triage labels

Use these GitHub label names when a skill refers to a triage role.

| Skill role | GitHub label | Use when |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | A maintainer needs to evaluate the request. |
| `needs-info` | `needs-info` | The reporter needs to provide specific information. |
| `ready-for-agent` | `ready-for-agent` | The scope and acceptance criteria are clear enough for an agent to implement. |
| `ready-for-human` | `ready-for-human` | The work requires human implementation. |
| `wontfix` | `wontfix` | The maintainer has decided to decline the work. |

Keep issue-type labels such as `bug` and `enhancement` alongside the triage label. Check which labels exist with `gh label list` before applying an unfamiliar one.
