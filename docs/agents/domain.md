# Domain docs

MewHelp uses a single context. Read the root `GLOSSARY.md` and the relevant records under `docs/adr/` when they exist. Use [the existing design notes](../superpowers/specs/) and the code to establish terminology and requirements when those files are absent.

Use the glossary's terms in issue titles, test names, and design proposals. When a change conflicts with an ADR, cite the decision and explain what needs revisiting. Add glossary entries or ADRs when the project settles a term or decision.
